# Passage Counter / 通過カウンター

スマートフォンやPCのカメラを固定して、画面上の一本の線を横切る人物を**方向別に自動カウント**するツールです。AIモデル、JavaScriptローダー、SIMD／非SIMDのWASMを含むすべての実行ファイルを**単一HTMLに内包**しています。

**v0.2.0は技術検証版です。** 人物追跡と通過判定は改善しましたが、**実環境での精度確認は未完了**です。安全管理、料金計算、法的な報告など、件数の正確さが重要な用途では独立した確認が必要です。

## 主な機能

- 「カメラを開始」を押してから権限を要求・カメラ映像を表示
- EfficientDet-Lite0（int8）とMediaPipe Tasks Visionで人物検出
- 両端をドラッグできる判定線、方向の反転、位置予測・矩形重なりによる短時間追跡、ヒステリシス付き線分通過判定と双方向カウント
- 計測開始・一時停止・再開・終了、経過時間、CSV書き出し
- 日本語／英語切替、スマホ対応、スリープ防止の試行
- アカウント・インストール・CDN・外部AI API・自動送信・録画は不要

## 使い方

1. HTMLをHTTPSまたはカメラを許可するブラウザの \`file://\` で開きます。
2. スマホ／カメラを固定し、通路全体を画面に収めます。
3. 「カメラを開始」を押して許可します。線の両端の白丸を動かして位置を決めます。
4. 必要ならA/B方向を反転して計測を開始します。計測中は画面を表示したままにします。
5. 一時停止・再開・終了を操作し、CSVを保存します。

**人数ではなく通過イベント数**です。同じ人物が戻ってきた場合は別件として数えます。混雑、遮蔽、逆光、暗所、カメラ移動などで誤差が生じます。

## 処理場所・プライバシー

映像解析と一時的な追跡情報はブラウザ内で処理します。音声は取得せず、映像・画像・顔を保存／送信しません。v0.2.0のイベントはメモリ内で保持し、CSVを選んだ場合のみローカルファイルとして出力します。**再読み込み・タブ終了で未保存の結果は失われます**。自動保存・復帰はv0.4.0で予定しています。

CSPの \`connect-src blob:\` は内包WASMをメモリのBlob URLから読むための許可で、外部HTTP/HTTPSの宛先は認めません。公共空間・職場では撮影範囲や告知について確認してください。

## 対応環境・制限

PC／AndroidのChrome・Edgeを主な検証対象とします。Safari・Firefoxは実機確認が必要です。カメラ権限、WebAssembly、圧縮データ展開への対応が必要です。\`file://\`のカメラ可否はブラウザ依存です。画面を隠した場合は計測が中断し、欠測分は数えられません。

## ビルドと単一HTML

最新の[htmlapps-template](https://github.com/ttomohisa/htmlapps-template)に沿って構成しています。編集するのは \`src/index.template.html\`、生成物を手で編集しません。

\`\`\`powershell
.\scripts\check-powershell-syntax.ps1
.\scripts\check-repository.ps1
\`\`\`

モデルとnpmライブラリは**ビルド時のみ**ダウンロードし、SHA-256を照合してHTMLへ内包します。配布物の動作時に追加ダウンロードは行いません。

出力は \`dist/index.html\`、\`dist/index.self-extract.html\`、ルートの \`passage-counter.html\` です。内包アセットとサイズは \`dist/\` のマニフェストを確認してください。CIの疑似カメラテストはモデル初期化と外部通信の有無を確認するもので、実環境の計測精度を保証しません。
