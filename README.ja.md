# Passage Counter / 通過カウンター

スマートフォンやPCのカメラを固定して、画面上の一本の線を横切る人物を**方向別に自動カウント**するツールです。AIモデル、JavaScriptローダー、SIMD版WASMとローダーを含むすべての実行ファイルを**単一HTMLに内包**しています。

**このブランチはSIMD専用のv0.3.0技術検証版であり、正式採用版ではありません。** WebAssembly SIMD非対応のブラウザではカメラを起動できず、許可要求前に理由を日英で案内します。 人物追跡と通過判定は改善しましたが、**実環境での精度確認は未完了**です。安全管理、料金計算、法的な報告など、件数の正確さが重要な用途では独立した確認が必要です。

## 主な機能

- 「カメラを開始」を押してから権限を要求・カメラ映像を表示
- EfficientDet-Lite0（int8）とMediaPipe Tasks Visionで人物検出
- 両端をドラッグできる判定線、方向の反転、位置予測・矩形重なりによる短時間追跡、ヒステリシス付き線分通過判定と双方向カウント
- **30秒の設置テスト**（途中終了可能）。テスト件数は本計測に含めません
- 方向別**+1/-1補正・Undo**。自動カウントの履歴は消さず、補正と取り消しをCSVに記録
- カメラの前面/背面切替、検出枠の表示ON/OFF、方向名の編集、端末内への設定保存
- 計測開始・一時停止・再開・終了、経過時間、CSV書き出し
- 日本語／英語切替、スマホ対応、スリープ防止の試行
- アカウント・インストール・CDN・外部AI API・自動送信・録画は不要

## 使い方

1. HTMLをHTTPSまたはカメラを許可するブラウザの \`file://\` で開きます。
2. スマホ／カメラを固定し、通路全体を画面に収めます。
3. 「カメラを開始」を押して許可します。線の両端の白丸を動かして位置を決めます。
4. 必要ならA/B方向を反転し「30秒テストを開始」を押します。途中終了も可能です。テスト件数は本計測に加算されません。
5. 「計測を開始」を押し、画面を表示したまま運用します。誤カウントは方向別の±1で補正し、直前の補正はUndoできます。
6. 一時停止・再開・終了を操作し、CSVを保存します。

**人数ではなく通過イベント数**です。同じ人物が戻ってきた場合は別件として数えます。混雑、遮蔽、逆光、暗所、カメラ移動などで誤差が生じます。

## 処理場所・プライバシー

映像解析と一時的な追跡情報はブラウザ内で処理します。音声は取得せず、映像・画像・顔を保存／送信しません。判定線、方向名、前面/背面、表示設定は端末のローカルストレージへ保存します（画像・カメラ個体のIDは保存しません）。v0.3.0のイベントはメモリ内で保持し、CSVを選んだ場合のみローカルファイルとして出力します。**再読み込み・タブ終了で未保存の結果は失われます**。自動保存・復帰はv0.4.0で予定しています。

CSPの \`connect-src blob:\` は内包WASMをメモリのBlob URLから読むための許可で、外部HTTP/HTTPSの宛先は認めません。公共空間・職場では撮影範囲や告知について確認してください。

## CSVの内容

列は `event_id`, `occurred_at`（UTCのISO形式）, `direction`, `direction_label`, `kind`（`auto` / `correction` / `undo`）, `delta`, `elapsed_ms`, `undo_of` です。Undoは元の補正イベントIDを参照します。**設置テストの件数はCSVに入りません**。同一人物の往復は別々の通過イベントです。

## SIMD専用版の実測サイズ

同じモデル・同じ計測UIのHTMLで **13,505,896バイト → 9,150,133バイト（4,355,763バイト、32.25%削減）** をCIで確認しました。SIMD対応端末での推論自体が速くなる変更ではありません。実機測定とサポート環境確認は未完了です。[検証記録](docs/ADR-002-SIMD-ONLY.md)。

## 対応環境・制限

WebAssembly SIMDへの対応が必要で、非対応ブラウザには事前に説明を表示します。PC／AndroidのChrome・Edgeを主な検証対象とします。Safari・Firefoxは実機確認が必要です。カメラ権限、WebAssembly、圧縮データ展開への対応が必要です。\`file://\`のカメラ可否はブラウザ依存です。画面を隠した場合は計測が中断し、欠測分は数えられません。

## ビルドと単一HTML

最新の[htmlapps-template](https://github.com/ttomohisa/htmlapps-template)に沿って構成しています。編集するのは \`src/index.template.html\`、生成物を手で編集しません。

\`\`\`powershell
.\scripts\check-powershell-syntax.ps1
.\scripts\check-repository.ps1
\`\`\`

モデルとnpmライブラリは**ビルド時のみ**ダウンロードし、SHA-256を照合してHTMLへ内包します。配布物の動作時に追加ダウンロードは行いません。

出力は \`dist/index.html\`、\`dist/index.self-extract.html\`、ルートの \`passage-counter.html\` です。内包アセットとサイズは \`dist/\` のマニフェストを確認してください。CIの疑似カメラテストはモデル初期化と外部通信の有無を確認するもので、実環境の計測精度を保証しません。
