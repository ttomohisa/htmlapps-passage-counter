# Passage Counter / 通過カウンター

スマートフォンやPCのカメラ、または端末内に保存された動画から、画面上の一本の線を横切る人物の通過を**方向別に自動カウント**するツールです。AIモデル、JavaScriptローダー、SIMD版WASMとローダーを含むすべての実行ファイルを**単一HTMLに内包**しています。

**このブランチはSIMD専用のv0.8.0精度評価準備版であり、正式採用版ではありません。** WebAssembly SIMD非対応のブラウザではカメラを起動できず、許可要求前に理由を日英で案内します。 人物追跡と通過判定は改善しましたが、**実環境での精度確認は未完了**です。安全管理、料金計算、法的な報告など、件数の正確さが重要な用途では独立した確認が必要です。

## 主な機能

- **カメラ／端末内動画の2入力モード**。動画は選択・ドラッグ＆ドロップ、プレビュー・シーク、先頭からの計測が可能
- **動画内の時刻（`source_time_ms`）をイベントCSVに記録**。シーク・再解析の際は確認し、前の件数・補正を消して二重計数を防止
- 動画本体のアップロード・永続保存・外部通信なし。ブラウザ標準デコーダだけを利用
- 「カメラを開始」を押してから権限を要求・カメラ映像を表示
- EfficientDet-Lite0（int8）とMediaPipe Tasks Visionで人物検出
- 両端をドラッグできる判定線、方向の反転、位置予測・矩形重なりによる短時間追跡、ヒステリシス付き線分通過判定と双方向カウント
- **30秒の設置テスト**（途中終了可能）。テスト件数は本計測に含めません
- 方向別**+1/-1補正・Undo**。自動カウントの履歴は消さず、補正と取り消しをCSVに記録
- カメラの前面/背面切替、検出枠の表示ON/OFF、方向名の編集、端末内への設定保存
- **IndexedDBへ逐次保存**。保存済みセッションの一覧・名前変更・削除・中断状態からの復帰（自動再開はしない）
- 有効計測・一時停止・欠測を区別し、5/15/60分の時間帯別集計と表示
- **イベント・概要・時間帯の3種類のCSV**。補正・Undoと欠測情報を保ったまま書き出し
- 保存不可時の明確な警告と、メモリ上の記録をCSVで救出する導線
- 計測開始・一時停止・再開・終了、経過時間表示
- **動作速度の把握と調整**：最新フレームだけの推論、処理時間に応じた間隔（105〜225ms）、一般ユーザー向けの「認識中」「処理が遅い」表示。fpsやモデル名は「処理の詳細」へ格納
- **安全な中断**：処理速度が長く低下した場合、無理に人数を数えず中断。画面非表示や向き変更での中断、画面スリープ防止の解除・後着レスポンスへの対応
- **メモリ・UI軽減**：初期化後の復号済みWASM・モデルのキャッシュと一時URL解放、チェックポイント保存と画面描画の分離、時間帯表示の更新頻度調整
- 日本語／英語切替、スマホ対応、スリープ防止の試行
- アカウント・インストール・CDN・外部AI API・自動送信・録画は不要

## 使い方

1. HTMLをHTTPSまたはカメラを許可するブラウザの \`file://\` で開きます。
2. スマホ／カメラを固定し、通路全体を画面に収めます。
3. 「カメラを開始」を押して許可します。線の両端の白丸を動かして位置を決めます。
4. 必要ならA/B方向を反転し「30秒テストを開始」を押します。途中終了も可能です。テスト件数は本計測に加算されません。
5. 「計測を開始」を押し、画面を表示したまま運用します。誤カウントは方向別の±1で補正し、直前の補正はUndoできます。
6. 一時停止・再開・終了を操作し、イベント・概要・時間帯別のCSVを保存します。欠測は0件として扱いません。
7. 再読み込み後は「保存した計測」から履歴を開けます。未終了の計測は停止状態で復帰し、再度カメラ起動と設置テストを実施してから手動で再開します。

**人数ではなく通過イベント数**です。同じ人物が戻ってきた場合は別件として数えます。混雑、遮蔽、逆光、暗所、カメラ移動などで誤差が生じます。

## ローカル動画の解析方法（v0.5.0）

「入力映像」から**端末の動画**を選び、MP4／WebMなどブラウザが再生できるファイルを指定します。ドラッグ＆ドロップにも対応します。動画は一時的なBlob URLで再生し、ファイルを丸ごとメモリに読み込んだり、外部サーバーへ送ったりしません。

プレビュー再生やシークで判定線を置いたら「計測を開始」を押します。**必ず動画の先頭へ戻して解析**し、動画終了時に自動で計測を終えます。途中でシークする場合は前の件数・補正・保存済み解析の破棄を確認し、取り消す場合は元の記録を保持します。ブラウザ側で意図せず再生位置が飛んだ場合も計測を中断します。30秒の設置テストはカメラ用で、動画では必要ありません。

イベントCSVの**`source_time_ms`**に動画中の再生時刻（ミリ秒）を記録します。概要CSVの`source_type`は`file`です。5/15/60分の時間帯別集計は**解析した実時間**に基づき、動画内の時刻ではありません。動画の時系列を確認するときは`source_time_ms`を利用してください。

映像データ、ファイル名、Blob URLはIndexedDBへ保存しません。再読み込み後も件数・履歴・CSVは確認できますが、動画の自動再開はできません。再解析には動画の選び直しが必要です。動画形式の対応はブラウザとOSに依存し、例えばMP4のH.264、WebMのVP8/VP9、MOV/HEVC等で差があります。変換ライブラリは内包しません。再生時間を取得できないWebMではブラウザ内で長さを調べ、なお不明ならシークを無効にして再生・計測を優先します。

## 処理場所・プライバシー

映像解析と一時的な追跡情報はブラウザ内で処理します。音声は取得せず、映像・画像・顔を保存／送信しません。判定線、方向名、前面/背面、表示設定は端末のローカルストレージへ保存します（画像・カメラ個体のIDは保存しません）。v0.5.0では**計測名、イベント履歴、補正・Undo、観測・一時停止・欠測区間をIndexedDBへ逐次保存**します。動画解析の場合は入力種類と動画内時刻・動画の長さのみを追加し、動画ファイル本体やファイル名は保存しません。映像・画像・音声・人物固有の追跡IDは保存しません。イベント発生時はイベントとセッション情報を同一トランザクションで保存し、約5秒ごとにも状態を保存します。ブラウザクラッシュで直前の未コミット記録が失われる可能性や、容量不足・プライベートモードで保存できない可能性は残ります。保存失敗時は警告を表示し、CSV出力で救出できます。`file://`版とHTTPS版は通常、同じ記録を共有しません。

CSPの \`connect-src blob:\` は内包WASMをメモリのBlob URLから読むための許可で、外部HTTP/HTTPSの宛先は認めません。公共空間・職場では撮影範囲や告知について確認してください。

## 中断と復帰

タブの非表示・カメラの停止・推論エラー時は欠測として記録し、自動では計測を再開しません。異常終了後は最後の保存済みチェックポイントまでを有効観測とし、それ以降は欠測と見なします。一時停止区間は別に記録します。セッションは同じブラウザ内で復帰できます。カメラは再開前に設置テストが必要です。動画の記録は件数とCSVを閲覧できますが、動画ファイルの選び直しなしで自動再生・解析再開することはありません。複数タブで同一の計測を同時編集する使い方は未検証です。

## CSVの内容

列は `event_id`, `occurred_at`（UTCのISO形式）, `direction`, `direction_label`, `kind`（`auto` / `correction` / `undo`）, `delta`, `elapsed_ms`, `undo_of` です。Undoは元の補正イベントIDを参照します。追加で `session_id` / `source_time_ms` / `event_kind_v1` / `reference_event_id` を出力します。概要CSVには自動・補正・確定件数と観測／一時停止／欠測の時間、時間帯CSVには選択した5・15・60分区間の件数・有効秒・欠測秒・カバレッジ区分が入ります。時刻はISO UTCとタイムゾーン識別子で扱います。**設置テストの件数はCSVに入りません**。同一人物の往復は別々の通過イベントです。

## 処理速度と実機検証の状況

v0.6.0は1つ前のフレーム処理が終わる前に次をキューへためません。SIMD版の推論にかかった時間をもとに処理間隔を調整し、極端な速度低下（約2.8fps未満または推論390ms超が8秒程度持続）では欠測を隠さず計測を中断します。Worker/OffscreenCanvasを用いてMediaPipeを別スレッドへ移動する方式は、モデル・Blob・ブラウザ互換性が成立するか未検証であり、**実装済みとはしていません**。

Windows Chromeの疑似カメラで20秒間動作させたところ、**約8.6fps、平均推論87ms**、測定時点のJSヒープ使用量は約5.3〜5.5MBでした。**スマホの速度、プロセス全体のピークメモリ、30分連続動作、実際の通過精度の証明ではありません。** 中級スマホで8fps、実機30分試験の達成可否は引き続き評価します。

## 対応環境・制限

WebAssembly SIMDへの対応が必要で、非対応ブラウザには事前に説明を表示します。PC／AndroidのChrome・Edgeを主な検証対象とします。Safari・Firefoxは実機確認が必要です。カメラ権限、WebAssembly、圧縮データ展開への対応が必要です。\`file://\`のカメラ可否はブラウザ依存です。画面を隠した場合は計測が中断し、欠測分は数えられません。
